# Agentic Documentation A/B Evaluation

Does adding generated agentic documentation (AGENTS.md + `agentic/` tree) improve AI coding agent performance on coding tasks?

**Campaign:** agentic-docs-ab-eval · **Date:** 2026-07-24 · **Claude Code:** 2.1.218

## Conditions

| Condition | Config | Description |
|-----------|--------|-------------|
| Baseline | `eval-baseline.yaml` | CLAUDE.md only, no agentic docs |
| Treatment-v1 | `eval-treatment.yaml` | Agentic docs present, no explicit read instruction |
| Treatment-v2 | `eval-treatment-v2.yaml` | Agentic docs present + AGENTS.md read instruction in system prompt |

## Recent Scores (task_success, 1–5)

| Condition | Mean |
|-----------|------|
| Baseline | 3.98 |
| Treatment-v1 | 3.86 |
| Treatment-v2 | 3.91 |

High-complexity tasks showed the only directional improvement (+0.20 for v2). Full breakdown in [RESULTS.md](RESULTS.md).

## Caveats

- **Repo asymmetry:** cert-manager-operator has no CLAUDE.md; multiarch-tuning-operator does. This may inflate baseline performance for cert-manager tasks.
- **Self-assessment bias:** LLM judges use the same model family (claude-opus-4-6) as the evaluated agent.
- **Synthetic tasks:** Tasks are coding prompts, not real PRs or issues.
- **Generated docs:** Agentic docs were generated by `/create-agentic-docs`, not human-authored; quality scores are self-assessed.
- **Efficiency judge flaw (historical):** The 15 published runs all scored 0 on efficiency — the judge used run-level totals unavailable at judge time. Fixed in config for future runs (now reads per-case `run_result.json`).
- **Treatment-v1 doc consultation:** 0% — agent never opened agentic docs without an explicit instruction.
- **Statistical power:** n=55 pairs per condition; designed for d≈0.5 but actual effects were d<0.2 (negligible). Study is underpowered for the effects observed.
- **Treatment-v2 traces (partial):** Traces were reconstructed post-run from `stdout.log` via `trace_builder.py`. Runs 1 and 4 have partial linkage (8/11 and 5/11) due to a pre-existing FOREIGN KEY constraint in the harness; runs 2, 3, 5 have all 11 linked.
