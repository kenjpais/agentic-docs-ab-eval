## Reproduce

```bash
# 1. Install claude-code 2.1.218 and agent-eval-harness (same versions)
# 2. Authenticate: set ANTHROPIC_API_KEY or run: claude login
# 3. Checkout repos at pinned SHAs — do NOT re-run /create-agentic-docs
#    (skill is not bit-stable; use frozen docs under repos/*-treatment/)
git -C repos/cert-manager-operator-baseline    checkout 849995ea92d1a795c72fb1ea2f266ee147ded275
git -C repos/cert-manager-operator-treatment   checkout 849995ea92d1a795c72fb1ea2f266ee147ded275
git -C repos/multiarch-tuning-operator-baseline  checkout 21943765a028587358bcec768bb81fd9979c9a83
git -C repos/multiarch-tuning-operator-treatment checkout 21943765a028587358bcec768bb81fd9979c9a83

# 4. Run (log under a new experiment name to avoid polluting the original data)
/eval-run --config eval-baseline.yaml      --run-id baseline-repro-1      --experiment agentic-docs-ab-eval-replication-YYYYMMDD
/eval-run --config eval-treatment-v2.yaml  --run-id treatment-v2-repro-1  --experiment agentic-docs-ab-eval-replication-YYYYMMDD

# Expect similar direction and magnitude; not identical scores (model non-determinism)
```

All experiment metadata (pinned SHAs, model versions, quality scores, platform) is embedded in `mlflow.tags` and `mlflow.params` in each eval config and logged to MLflow on every run.

## Caveats

- **Repo asymmetry:** cert-manager-operator has no CLAUDE.md; multiarch-tuning-operator does.
- **Self-assessment bias:** LLM judges use the same model family (claude-opus-4-6) as the evaluated agent.
- **Synthetic tasks:** Tasks are coding prompts, not real PRs or issues.
- **Generated docs:** Agentic docs were generated by `/create-agentic-docs`, not human-authored; quality scores are self-assessed.
- **Treatment-v1 doc consultation:** 0% — agent never opened agentic docs without an explicit instruction.
